# neuroscience_sandbox
> **Disclaimer:** These scripts are exploratory learning exercises. They are not intended as validated or research-grade implementations! This repository documents my process of experimenting with these methods through simulation.

---

## Scripts
- `simulation_age_genexpression_first_try_two_genes.py`: Basic simulation linking lifespan brain volume trajectories with gene expression trends (very basic regression with simulated brain volume metrics)
- `normative_modeling_moving_avg.py`: Simulates a healthy reference cohort versus a clinical cohort to explore individual deviations and heterogeneity using a moving average
- `normative_modeling_gamlss.py`: Exploratory attempt to build a GAMLSS to fit a non-linear trajectory and heteroscedastic variance
    -> includes a smoother based implementation and an intentionally overfitted model for comparison.
